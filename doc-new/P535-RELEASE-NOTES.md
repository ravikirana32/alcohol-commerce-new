# P535 Release Notes

P535 adds signed provider webhook evidence intake, idempotent provider event storage, tender lifecycle records, cash denomination counts, settlement batch/item import, exact transaction matching, bank payout confirmation and a payment exception queue.

This is a developer-preview backend delivery. It does not enable live capture or claim provider certification. Admin UI, automatic checkout tender emission, full refund allocation/chargebacks, cash close variance approval and accounting journals remain open. P534 blockers are carried forward.
