# P500.7 — Bar multi-line ticket and idempotency integrity

Version: `0.500.7-dev`  
Status: developer preview; not production approved.

## Implemented
- Bar POS now builds multi-line tickets with PEG, BOTTLE and PACKAGED line types.
- Peg cart lines retain the selected open-bottle identifier and measure size.
- Ticket totals and split tenders are calculated across all lines and submitted as one atomic checkout.
- Bar cart supports line removal and clears only after confirmed checkout.
- Added canonical SHA-256 bar checkout fingerprints and migration 212.
- Reusing a bar idempotency key for a different request returns HTTP 409; legacy rows are reconstructed on replay.

## Verification
- Retail/bar checkout integration checks: 15/15 passed.
- TypeScript/TSX syntax transpilation: 212 files, zero syntax diagnostics.
- Migration static ordering: 211 SQL files passed.

## Limitations
- No real PostgreSQL transaction tests or multi-user concurrent peg tests.
- No bar ticket detail/refund user interface yet.
- No POS hardware or fiscal printer integration.
