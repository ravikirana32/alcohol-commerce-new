# P500.3 Retail Cart UI Integration

Version: `0.500.3-dev`  
Baseline: P500.2 retail checkout integrity remediation  
Scope: Complete the existing retail cart-to-checkout path; no new business feature.

## Implemented
- Retail POS can add multiple configured products to a cart.
- Adding the same configured price line increments its quantity rather than creating duplicate visual rows.
- Cart displays line quantity and calculated amount, with remove controls.
- Checkout submits all cart lines together to the existing atomic retail sale endpoint.
- Checkout amount is calculated across all cart lines and submitted as the tender total.
- If a checkout response is uncertain, the UI retains the exact request body and idempotency key, locks cart editing and offers a safe retry.
- On confirmed success, cart is cleared.
- Bar POS remains on its existing single-line atomic checkout workflow.
