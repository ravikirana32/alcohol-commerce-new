# General availability decision

**Decision: NOT APPROVED on the evidence available in this delivery.**

GA requires executed CI/build/test evidence, clean DB migration and restore drills, complete P0/P1 user journeys, penetration test with no open critical/high findings, signed Karnataka legal/excise mapping for each enabled operating mode, verified payment/hardware integrations, pilot acceptance and production operations sign-off. P301–P350 source delivery does not satisfy these gates by itself.
