# P197 — Bar and pub pilot

## Objective
Run a supervised bar pilot validating peg inventory, service and shift reconciliation.

## Deliverables
- [ ] Verify licence scope and authorised service measures
- [ ] Validate open bottle lifecycle and physical stock reconciliation
- [ ] Train staff on comps, wastage, breakage and shift close
- [ ] Capture pilot metrics, incidents and corrective actions

## Acceptance evidence required
- Executed unit, integration and relevant end-to-end tests.
- Demonstrated working UI/API workflow using a non-production environment.
- Database migration tested on a clean database and supported upgrade path.
- Tenant isolation, permissions, audit and failure paths reviewed.
- Operational owner sign-off and recorded unresolved risks.

## Safety and release constraints
- Do not enable service modes not explicitly authorised by the outlet licence
