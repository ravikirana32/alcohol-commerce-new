# P155 — Product usability and accessibility

## Objective
Improve usability for cashier, bartender, manager and administrator tasks, including accessible keyboard and assistive-technology operation.

## Deliverables
- [ ] Audit navigation, focus order, labels, contrast and error messages
- [ ] Optimise high-frequency billing and peg workflows
- [ ] Add responsive layouts and actionable empty/error states
- [ ] Record accessibility findings and remediation evidence

## Acceptance evidence
- Executed automated tests and attached report.
- Relevant API/UI workflow demonstrated in a non-production environment.
- Database migration tested both on a clean database and as an upgrade.
- Security, tenant-scope and permission checks reviewed.
- Operational owner signs off; unresolved issues are documented.

## Risks and controls
- Accessibility claims require automated and manual verification

## Delivery status
**Scope defined; implementation and acceptance are not claimed by this phase contract.**
