# P158 — Hybrid outlet deployment

## Objective
Validate hybrid retail and on-premise operations with licence-gated modes, shared stock controls and separate reporting.

## Deliverables
- [ ] Verify licence supports each operating mode
- [ ] Separate retail and bar transaction types and tax treatment
- [ ] Test shared stock movements without double counting
- [ ] Validate mode-specific cashiers, permissions and reports

## Acceptance evidence
- Executed automated tests and attached report.
- Relevant API/UI workflow demonstrated in a non-production environment.
- Database migration tested both on a clean database and as an upgrade.
- Security, tenant-scope and permission checks reviewed.
- Operational owner signs off; unresolved issues are documented.

## Risks and controls
- Hybrid mode must remain unavailable until legal permission is verified

## Delivery status
**Scope defined; implementation and acceptance are not claimed by this phase contract.**
