# P196 — Retail outlet pilot

## Objective
Run a limited supervised pilot with licensed retail outlets after all release gates pass.

## Deliverables
- [ ] Select pilot outlets and verify licence and operational readiness
- [ ] Train cashiers and managers using approved procedures
- [ ] Run parallel reconciliation and capture defects
- [ ] Define exit criteria, rollback and pilot acceptance report

## Acceptance evidence required
- Executed unit, integration and relevant end-to-end tests.
- Demonstrated working UI/API workflow using a non-production environment.
- Database migration tested on a clean database and supported upgrade path.
- Tenant isolation, permissions, audit and failure paths reviewed.
- Operational owner sign-off and recorded unresolved risks.

## Safety and release constraints
- Do not conduct live transactions before legal, security and release approval
