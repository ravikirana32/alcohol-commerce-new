# P171 — International market onboarding

## Objective
Create a repeatable onboarding framework for new jurisdictions without assuming one country's alcohol rules apply elsewhere.

## Deliverables
- [ ] Create jurisdiction profile and legal review checklist
- [ ] Localise currencies, languages, dates and tax configuration
- [ ] Map permitted outlet modes and reporting obligations
- [ ] Require country-specific acceptance before activation

## Acceptance evidence
- Executed automated tests and attached report.
- Relevant API/UI workflow demonstrated in a non-production environment.
- Database migration tested both on a clean database and as an upgrade.
- Security, tenant-scope and permission checks reviewed.
- Operational owner signs off; unresolved issues are documented.

## Risks and controls
- No jurisdiction is legally supported merely because configuration fields exist

## Delivery status
**Scope defined; implementation and acceptance are not claimed by this phase contract.**
