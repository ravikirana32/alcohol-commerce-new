# P161 — Distributor commercial intelligence

## Objective
Provide distributor performance visibility for authorised territories, assigned outlets, orders, fulfilment and claims.

## Deliverables
- [ ] Define distributor hierarchy and territory access
- [ ] Report order fill rate, delivery time and outlet coverage
- [ ] Track claims, returns and dispute status
- [ ] Export auditable commercial summaries

## Acceptance evidence
- Executed automated tests and attached report.
- Relevant API/UI workflow demonstrated in a non-production environment.
- Database migration tested both on a clean database and as an upgrade.
- Security, tenant-scope and permission checks reviewed.
- Operational owner signs off; unresolved issues are documented.

## Risks and controls
- Commercial visibility must be tenant- and relationship-scoped

## Delivery status
**Scope defined; implementation and acceptance are not claimed by this phase contract.**
