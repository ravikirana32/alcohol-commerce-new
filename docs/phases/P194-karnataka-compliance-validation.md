# P194 — Karnataka compliance validation

## Objective
Validate Karnataka-specific licence, excise, reporting and permitted operating workflows.

## Deliverables
- [ ] Map each operating profile to verified licence permissions
- [ ] Review excise records, reporting and retention requirements with qualified counsel
- [ ] Validate approved product, price, tax and service configurations
- [ ] Document regulator-facing evidence and compliance sign-off

## Acceptance evidence required
- Executed unit, integration and relevant end-to-end tests.
- Demonstrated working UI/API workflow using a non-production environment.
- Database migration tested on a clean database and supported upgrade path.
- Tenant isolation, permissions, audit and failure paths reviewed.
- Operational owner sign-off and recorded unresolved risks.

## Safety and release constraints
- No legal or excise compliance claim without qualified local professional validation
