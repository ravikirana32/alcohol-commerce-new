# P167 — Advanced fraud detection

## Objective
Detect suspicious stock, cash, refund, void, discount and account-access patterns with reviewable alerts.

## Deliverables
- [ ] Define explainable risk signals and thresholds
- [ ] Correlate stock variance with transaction and shift events
- [ ] Provide investigation workflow and evidence trail
- [ ] Measure false positives and provide appeal/correction process

## Acceptance evidence
- Executed automated tests and attached report.
- Relevant API/UI workflow demonstrated in a non-production environment.
- Database migration tested both on a clean database and as an upgrade.
- Security, tenant-scope and permission checks reviewed.
- Operational owner signs off; unresolved issues are documented.

## Risks and controls
- Alerts are not proof of misconduct; avoid automated punitive action

**Scope defined; implementation and acceptance are not claimed by this phase contract.**
