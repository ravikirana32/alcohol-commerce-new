# P156 — Karnataka retail deployment

## Objective
Prepare a controlled deployment for licensed Karnataka retail outlets with verified licence scope and local operational configuration.

## Deliverables
- [ ] Validate outlet licence documents and permitted operating profile
- [ ] Configure product, price, tax and excise rules only from approved sources
- [ ] Train retail staff and rehearse billing, returns and stock counts
- [ ] Run a supervised pilot with rollback and support procedures

## Acceptance evidence
- Executed automated tests and attached report.
- Relevant API/UI workflow demonstrated in a non-production environment.
- Database migration tested both on a clean database and as an upgrade.
- Security, tenant-scope and permission checks reviewed.
- Operational owner signs off; unresolved issues are documented.

## Risks and controls
- Qualified Karnataka excise/legal review is mandatory before live use

## Delivery status
**Scope defined; implementation and acceptance are not claimed by this phase contract.**
