# P183 — Inventory and procurement

## Objective
Complete procurement, receiving, transfers, stock counts and inventory valuation workflows.

## Deliverables
- [ ] Complete purchase orders, goods receipt and supplier invoice matching
- [ ] Track packaged stock and open-bottle millilitres separately
- [ ] Support approved inter-outlet transfers and stock count adjustments
- [ ] Add reorder rules, valuation and variance reports

## Acceptance evidence required
- Executed unit, integration and relevant end-to-end tests.
- Demonstrated working UI/API workflow using a non-production environment.
- Database migration tested on a clean database and supported upgrade path.
- Tenant isolation, permissions, audit and failure paths reviewed.
- Operational owner sign-off and recorded unresolved risks.

## Safety and release constraints
- Every adjustment must carry actor, reason, time and source reference
