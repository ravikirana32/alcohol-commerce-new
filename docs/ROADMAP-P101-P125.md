# P101–P125 delivery roadmap

## P101 — Full codebase audit

Inventory every package, route, screen, migration, dependency and workflow; produce traceable findings and remediation backlog.

## P102 — Build and compilation stabilisation

Resolve TypeScript, React, Node.js, workspace, dependency and container build failures with reproducible verification.

## P103 — Database integrity

Validate migration order, foreign keys, tenant boundaries, indexes, constraints, transaction safety and backup/restore procedures.

## P104 — API completion

Complete API contracts, validation, authorization, tenant scoping, error handling, idempotency and OpenAPI coverage.

## P105 — Frontend completion

Complete role-based operational screens, loading/error/empty states, accessibility, responsive layouts and API integration.

## P106 — Retail POS end-to-end

Complete barcode billing, pricing, discounts, returns, receipts, tenders, cash drawer and cashier shift workflows.

## P107 — Bar POS end-to-end

Complete table/service workflows, peg billing, open-bottle lifecycle, measure configuration and bill settlement.

## P108 — Inventory reconciliation

Complete bottle/ml stock ledger, wastage, breakage, transfers, variance investigation and shift reconciliation.

## P109 — Procurement and warehouse

Complete purchase requests, approvals, GRN, supplier returns, warehouse bins, transfers and supplier settlements.

## P110 — Finance and accounting

Complete journals, ledgers, payment settlement, tax configuration, invoice exports and accounting reconciliation.

## P111 — Brand portal completion

Complete brand onboarding, campaign lifecycle, outlet participation, scheme settlement and analytics.

## P112 — Distributor portal completion

Complete distributor onboarding, territory/outlet mapping, order fulfilment, delivery proof and collections.

## P113 — Trade partner application

Complete field-team mobile workflows, outlet visits, schemes, rewards, learning and offline-safe task execution.

## P114 — Enterprise administration

Complete group/company/region/outlet hierarchy, scoped roles, consolidated views and administration controls.

## P115 — Customer and loyalty completion

Complete customer profiles, consent, loyalty accrual/redemption, communication preferences and privacy workflows.

## P116 — Automated testing

Build unit, integration, API contract, UI and Playwright E2E suites with repeatable CI execution.

## P117 — Performance optimisation

Profile critical journeys, optimise SQL and caching, run load tests and define capacity thresholds.

## P118 — Security audit

Perform threat modelling, OWASP review, tenant isolation tests, secrets review, dependency scanning and penetration-test remediation.

## P119 — Offline and device validation

Validate offline billing, durable queues, idempotent sync, conflict handling, printers, scanners and terminal recovery.

## P120 — Production deployment

Implement CI/CD, environment promotion, observability, backups, disaster recovery, release gates and rollback procedures.

## P121 — SaaS commercialisation

Complete subscription plans, entitlements, trials, invoicing, usage metering, tenant onboarding and subscription lifecycle.

## P122 — Hardware and payment ecosystem

Integrate supported printers, scanners, cash drawers, payment terminals and payment gateway workflows.

## P123 — Partner integrations

Complete accounting, ERP, supplier and external platform adapters with secure credentials, retries and monitoring.

## P124 — Pilot and customer onboarding

Run controlled outlet pilots, training, support, feedback loops, operational sign-off and remediation.

## P125 — Enterprise general availability

Complete launch governance, support model, SLAs, release documentation, customer rollout and commercial readiness.

## Exit criteria

- Working UI/API/database workflows, not only schema or screen scaffolding.
- Automated tests and evidence must pass before phase completion.
- Qualified jurisdiction-specific review for excise, licensing, tax, privacy and age requirements.
- AI disabled by default; licence permissions externally verified.
- Pilot sign-off, recovery tests, monitoring, support readiness and rollback before launch.
