# P500.8 — Bar ticket history and refund workflow

Version: `0.500.8-dev`  
Status: developer preview; not production approved.

## Implemented
- Added organisation-scoped bar ticket list and ticket detail endpoints.
- Ticket detail returns ticket lines, tender payments and refund history.
- Added bar:read permission seed for retail owners/managers, bar owners and bartenders.
- Added Bar Tickets & Refunds workspace with ticket history, detail and refund entry.
- Refund UI supports amount, reason, refund method and reference; API remains permission-gated, row-locked and capped at remaining refundable value.
- Explicitly warns that a bar cash refund does not automatically reverse consumed peg volume.

- Bar ticket/refund checks: 9/9 passed.
- Retail sales/refund checks: 9/9 passed.
- Retail/bar checkout checks: 15/15 passed.

## Limitations
- No live DB/API/browser E2E, concurrency or payment-provider refund tests.
- Peg ml reversal is deliberately not automatic; a separately authorised physical stock adjustment is required.
- Role permission migration must be applied before users can access bar ticket history.
